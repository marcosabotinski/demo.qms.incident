# Phase 1 reference artifacts

This tree is the **Phase 1 reference artifact store** on the `solution` branch.

Facilitators use these Markdown notes after a live session so the Ask walkthrough, Canvas brief, Plan-mode pagination plan, documentation Skill, and subagent briefs are not lost if only product code later lands on `main`.

| Folder | Exercise |
|---|---|
| `01-ask/` | Ask mode — understand the Quality Incident Hub |
| `02-canvas/` | Canvas — architecture and quality-incident flow |
| `03-plan-pagination/` | Plan mode — paginate the incidents list |
| `04-docs-skill/` | Skill — create/update `documentation.md` |
| `05-subagents/` | Subagents — lifecycle explore + comment thread |

## What this is not

- Not a second copy of Cursor rules. Project rules stay in `.cursor/`. Do not duplicate them here.
- Not a solved product dump. Pagination, status transitions, and comment threads are **not** implemented in the app unless they already exist on this branch. These files describe the exercise, not the finished code.
- Workshop titles in `LAB.md` stay as titles only. Prompts and review notes live here.

Product-code solutions may land elsewhere or later. Keep this tree lab-neutral: **Acme Quality / eQMS**, Berlin Lab, no customer branding.
